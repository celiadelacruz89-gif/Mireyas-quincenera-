# Mireya Bertolli — A Winter Wonderland

Next.js scrollable quinceañera invitation with animated envelope, snowfall, music controls, countdown, gallery, and celebration details.

## Install and run

```bash
npm install
npm run dev
```

Open the forwarded port 3000 in GitHub Codespaces.

## Photos

Place the original JPG photos in `public/photos/`:
- `mireya-main.jpg`
- `mireya-1.jpg`
- `mireya-2.jpg`
- `mireya-3.jpg`

## Music

Place an appropriately licensed recording in `public/music/blue-velvet.mp3`. The envelope tap initiates playback, because mobile browsers normally block autoplay with sound without a user gesture. The player also has play/pause and mute controls.

## Deploy

Commit the files to GitHub, then import the repository at https://vercel.com/new. If the recording is not licensed for public use, do not publish the MP3; substitute licensed audio instead.
